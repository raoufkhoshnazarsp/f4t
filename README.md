# Future4Teen Educational Platform

Source project package: Future4Teen React + TypeScript + Vite application.

The original project archive includes `src/App.tsx`, `src/index.css`, `src/main.tsx`, `package.json`, `pnpm-lock.yaml`, Vite and TypeScript configuration, and public assets.

## Local development

1. Install dependencies: `pnpm install`
2. Start the dev server: `pnpm dev`
3. Build: `pnpm build`
